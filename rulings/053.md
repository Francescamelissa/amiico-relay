§1 — you already invented the right technique for this, two days ago

You proved gh-read's reds with a fake gh on the PATH — a fabricated input, no real state touched. Do the same here. The interlock gate reads the catalog; give it an injectable reading and feed it a fabricated row where the delete action is cascade. Its red path is then exercised without any real constraint ever being relaxed.

Relaxing the actual foreign key to produce the red is testing the gate with a live grenade. And note what the two assertions actually are, because they are different and only one of them needs a mutated schema at all:

Does the constraint still restrict? — prove it by exercising it: a pgTAP throws_ok on a delete that should be refused, asserting 23503. No schema change, tests the real constraint, and it is the stronger of the two tests.

Does the gate go red if someone relaxes it? — that is a test of the gate, and a gate should be testable from a fabricated reading rather than from a real catalog someone has damaged.

Prove a constraint by exercising it, not by removing it.

§2 — a probe migration in supabase/migrations/ is not a probe

If any probe migration is committed there even transiently, stop. That directory is a medium that applies what it contains — anything placed in it will be applied, which is the whole point of it. A file that relaxes a safety constraint, sitting beside the real migrations, is indistinguishable from an instruction to relax it. Production migrations on this project are applied by hand, with no record of what is live — that is risk 03 and it is unresolved — so the path from "committed for a CI red" to "applied to production by someone running a push while it is in the tree" is one command long.

This is the interpretation parent again, in the most consequential medium we have: the sentinel inside its own value space, the example beside the record, the comment in directive syntax, and now the probe beside the migrations. Add it as the fourth instance.

If the revert has already run, nothing is wrong — but say in the write-up that the red was produced by mutating a real constraint, so the record shows how it was obtained. And do not do it that way again.
