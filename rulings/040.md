# Ruling 040 — the taint is a window, not a command — enumerate every reading inside it; the empty-corpus check; a scan of nothing never passes; [] joins the sentinel list

---

§1 — the taint is a window, not a command

Do not fix only the ruleset reads. Every invocation between the Xcode update at 20:24:45 and the moment the toolchain was settled had the same failure available to it, including the ones that reached git indirectly — you already observed the licence line leaking from two commands that ran no git of their own.

So: define the window by timestamps, enumerate every reading, count and gate result recorded inside it, and mark them all tainted until re-taken. Not judged individually on whether they look plausible — a tainted reading that happens to be correct is still a reading nobody took, and the whole point of this project's method is that we do not keep facts we cannot source.

§2 — the one that would worry me most

You noted the secret-boundary gate runs git ls-files. In that window, git ls-files returned nothing. A gate that enumerates its input through git and then scans what it found would have scanned zero files and reported green.

Check whether any gate in the composite passed inside that window on an empty input set. That is not a stale reading; that is a gate reporting a clean result on a corpus it never had — and it is the precise failure the denominator rule was written for, arriving through a door we had not thought of.

§3 — the permanent fix, and it files under a parent we already have

Every gate that enumerates its own input asserts a non-zero denominator wherever zero is impossible, and reds rather than passes when the corpus is empty. Two hundred and five files is a number the privacy-claims gate already reports; make the reporting an assertion rather than an observation, and do the same everywhere a gate counts what it looked at. A scan of nothing must never be a pass.

And on the filing — resist making this a new clause. [] means both there are no rulesets and I could not tell you. That is a sentinel living inside the value space of the thing it represents, which is already in the book with 0,0, '', 0 and 1970-01-01 beside it. Empty joins that list. The parent earns its keep by absorbing this rather than by being joined by a cousin.

Underneath it, the operational form: a read that returns must still prove it succeeded. Exit status checked and asserted, not inspected by eye — and for gh, a positive control alongside the list call, because a call that returns the repository's own name proves the credential and the toolchain were working when the empty list came back.
