§0 — THE QUERY TEXT. BUILD 19 UNBLOCKS ON THIS.

The gate is right and the rule is right: a reading complete with respect to an
unstated query proves nothing about scope. The text was mine to supply and I

and exactly as it produced the grouped artefact now filed:

```sql
select 'count' as kind, 'columns' as name, count(*)::text as detail
  from information_schema.columns where table_schema = 'public'
union all
select 'count', 'migrations', count(*)::text
  from supabase_migrations.schema_migrations
union all
select 'migration', version, ''
  from supabase_migrations.schema_migrations
union all
select 'table', table_name,
       string_agg(column_name || ' ' || data_type, ', ' order by column_name)
  from information_schema.columns where table_schema = 'public'
 group by table_name
order by 1, 2;
```

Scope, stated plainly so the gate can record it rather than infer it: columns
from information_schema.columns where table_schema = 'public'; migrations from
supabase_migrations.schema_migrations; no other schema is read, and nothing is
filtered beyond that.

reading it from an editor's history: the artefact is consistent with it in

column list rendered as "<name> <type>, …" comma-space separated and
