§1 — before any conversion work: what does home_currency actually hold?

The two Thailand rows on the server both carry home_currency = THB. THB is the destination's currency, not the home currency of a user in the United Kingdom. The founder is now setting a Mexico budget in MXN.

So establish what writes that column and what it is meant to mean. If it holds the destination currency, the field's name is a lie, and the person who later builds conversion on top of it will convert in the wrong direction and every figure in the app will be confidently wrong. Fix the meaning before anything depends on it — a rename, or a second column, or both. This is the sentinel family again in a different guise: a name that describes one thing while the column holds another.

§2 — the conversion design, so it is scoped before it is wanted

Red lane, held, but here is the shape so nobody builds the expensive version by accident.

Version one takes no external service. A user-entered rate per trip, stored as a rate — which is a fact, not a derived amount — with the date it was entered. Conversion is display-only: never stored as money, never summed into a total that anything else reads, never written back. Money stays integer minor units in its original currency, and the authority rule holds — whoever writes the original amount owns it, and a converted figure is a rendering, not a record.

Every converted figure prints its rate and the date of that rate beside it. A number that cannot be checked is a claim, and the app does not make claims it cannot support.

A live rate provider is a separate decision and a separate hold: new third party, notice change, recipient count in the privacy-claims gate, licence, cost, offline degradation, and the retroactivity problem. Version one does not become version two by adding a fetch — it becomes version two by answering all of that first.

§3 — two things visible on the budget screen that are not about budgets

There is a Push notifications toggle. Notifications are not built — the status page has them as not built, needing the phone's permission. So that switch can be turned on and nothing will ever arrive. Off by default is the safe state, which is why this has not bitten yet, but a control that accepts input and does nothing is a promise made in one system about a capability that lives in another, and it is the fifth instance we have found. Wire it, disable it with a line saying why, or remove it.

And APPLIES TO — Whole trip / Just me draws a distinction that cannot currently differ, since companions do not exist. Benign today because both produce the same number. Worth a note in the file rather than an action, so that whoever builds splitting finds it already flagged rather than discovering that the control shipped eighteen months before it meant anything.
